# QuickTask

A tiny todo app I built in a weekend to try out an idea. Users can add tasks,
mark them done, and get a daily summary by email.

> Heads up: this repository exists **only** to demo an automated code scanner.
> Every credential in it is fake and every weakness is deliberate. Do not copy
> any of this code into a real project.

## Run it

```
pip install -r requirements.txt
python app.py
```

Frontend is the static files in `public/`.
